Tavern Drop 안내

15라인 좌표는 공개 데모에서 관찰했으며, 결과는 합성 데이터입니다. 이 화면의 규칙은 임시 목 예제이며 최종 게임 규칙은 별도 승인됩니다. 원작의 당첨 확률을 재현한 버전이 아닙니다.

게임 흐름

라인의 왼쪽부터 같은 심볼이 3개 이상 연결되면 당첨됩니다. 와일드는 보너스 심볼을 제외한 심볼을 대신합니다.

보너스 심볼 3개는 무료 스핀 10회, 무료 스핀 중 3개는 5회 추가를 발동합니다. 보너스에서 한 릴의 다섯 칸을 모두 당첨으로 채우면 해당 상자가 해제됩니다. 공개한 상자 배수는 보너스 마지막에 서로 곱해집니다.

라인을 선택한 뒤 안내창을 닫으면 릴 위에서 경로를 볼 수 있습니다. 공개 데모에서 관찰한 경로이며, 백엔드와의 라인 식별자 매핑·수학 계약은 별도로 확인합니다.
